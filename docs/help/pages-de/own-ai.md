# Eine eigene KI {#your-own-ai}

Der Nextcloud-Agent arbeitet nur mit dem Fadenstack-Server Ihrer Organisation. Es gibt keine Einstellung, um eine
eigene KI anzubinden, etwa ein Modell auf Ihrem Computer oder ein Konto bei einem KI-Anbieter.

## Warum {#why}

Der Agent arbeitet mit den Dateien Ihrer Organisation, nach den Regeln Ihrer Organisation. Der Fadenstack-Server
Ihrer Organisation entscheidet, welches Modell antwortet, prüft jeden Tool-Aufruf, bevor er läuft, führt die
Aufzeichnungen, die Ihre Organisation braucht, und signiert die Kennzeichnungen, die zeigen, was KI-generiert ist.
Ohne diesen Server startet der Agent nicht.

## Was Sie stattdessen tun können {#what-you-can-do-instead}

- **Fragen Sie Ihren Administrator** nach Zugriff auf den Agenten auf dem Server Ihrer Organisation: siehe
  [Erste Schritte](get-started.md).
- **Die anderen Agenten von Fadenstack** können mit einer eigenen KI arbeiten: der Browser-Agent, die
  Office-Add-ins und die Desktop-App. Siehe [Browser-Agent](../chrome/index.md),
  [Office-Add-ins](../office/index.md) und [Desktop-App](../desktop/index.md).
