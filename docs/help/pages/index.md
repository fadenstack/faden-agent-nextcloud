# Nextcloud agent

The Fadenstack agent works in Nextcloud Files. It finds your files, reads the one you include, answers questions about
it, and writes text files for you, each one only after you allow it. It works with your organisation's Fadenstack
server and the models your organisation offers there.

<!-- picture: index/drawer.png — Files with the agent's panel open on the right: a file included, a question, an answer with a passage and its source -->

## What you can do with it

- Find files by name, type, folder or date: "Find the latest supplier contract".
- Ask about a file you include: "What is the notice period?" The answer shows the passage and links to it.
- Have it write a summary, notes or a draft as a `.md` or `.txt` file, or update one. You see the whole text before
  anything is saved, and you allow each change.
- See where an answer or a file came from: what the agent writes is marked as made by AI, unless it needs no mark
  (see [AI marks](ai-marks.md)).
