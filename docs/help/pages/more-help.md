# More help

Where to read more about the Nextcloud agent, and where to ask.

## The instructions for use {#instructions-for-use}

The instructions for use describe what the agent is for, what it can do, its limits, the administrator's settings,
what is logged and where, and the known risks. They will be published with the agent's legal documents:
[fadenstack.com/legal/nextcloud](https://fadenstack.com/legal/nextcloud/).

## Privacy and terms

- [Privacy policy for the Nextcloud agent](https://fadenstack.com/legal/nextcloud/privacy/)
- [Terms for the Nextcloud agent](https://fadenstack.com/legal/nextcloud/terms/)

Your organisation's own privacy policy for its Fadenstack server applies too. Ask your administrator for it.

## Fadenstack's Help

The Nextcloud agent works with your organisation's Fadenstack server. These pages of Fadenstack's Help explain the
parts it shares with the server:

- [Sign in a desktop app](../../use/sign-in-an-app.md): approving a sign-in code, and ending a sign-in
- [Tools in the chat](../../use/tools.md): tool modes and approvals
- [Your data and privacy](../../use/privacy.md): what the server keeps, and who can see it
- [Checking content](../../use/checking-content.md): checking a text or a file for an AI mark
- [Agents and add-ins](../../administer/agents.md), for administrators: publishing an agent and giving people access

## Ask for help

- **At work**: ask your administrator first. They can see your organisation's settings for the agent.
- **Fadenstack's support**: [fadenstack.com/support](https://fadenstack.com/support/).
- **A problem in the app's code**: the app is free software, and its source and issue tracker are at
  [github.com/fadenstack/faden-agent-nextcloud](https://github.com/fadenstack/faden-agent-nextcloud).
- **A security problem**: report it as the support page says, not in a public issue.

This version receives security fixes until 8 December 2031.
